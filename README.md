# Pritam Kumar Portfolio

Live Demo: https://portfolio-beta-opal-l4.vercel.app/

A modern developer portfolio built using Next.js, React, Tailwind CSS, and TypeScript.  
This portfolio showcases my skills, projects, education, and experience in AI/ML and Full-Stack Development.

---

## 🚀 Tech Stack

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel

---

## ✨ Features

- Modern responsive UI
- Smooth animations
- Skills section
- Projects showcase
- Contact section
- Resume download
- Fully responsive design
- Dark futuristic theme

## 🛠️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/pritam1952/Portfolio.git
```

Move into the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 📦 Build for Production

```bash
npm run build
```
